# Operational Runbook: Gradient Field Routing Fault Matrix

This document breaks down the deterministic behavior of the routing engine under core system degradation scenarios.

| Failure Event | Immediate System Impact | Recovery / Mitigation Architecture |
| :--- | :--- | :--- |
| **Worker Compute Lag** *(Execution outruns `ROUTING_IDEMPOTENCY_TTL_SECONDS`)* | The initial thread loses its lock mid-flight. Another request claims the slot. | The late-running thread triggers `LUA_COMPLETE_IF_MATCH`. The script safely rejects the write because tokens do not match, returning a `409 Conflict`. No data corruption or lock stomping occurs. |
| **Redis Node Outage / Crash** *(Connection pool throws a socket exception)* | The proxy cannot acquire locks, read replays, or update routing targets. | The route handler falls into the general `except` block, safely registers a critical alert to the telemetry pipeline, and issues an internal `500 Server Error`. The borrowed Rust router is safely returned to the `asyncio.Queue` via the `finally` layout block, preventing memory leaks. |
| **Asynchronous Client Retries** *(Client submits the same UUID mid-computation)* | The client fires duplicate payloads during high-traffic bottlenecks. | The incoming connection encounters the `cache.set(..., nx=True)` boundary gate. The atomic check fails, and the middleware immediately issues a clean `202 Accepted` along with a standardized `Location` link to the tracking status module. |
| **Physical Worker Node Crash** *(Operating System / Docker container dies mid-flight)* | The active thread calculation vanishes instantly. The borrowed Rust instance is unreturned. | The distributed lock inside Redis stays locked until its natural 60-second TTL expires. Once dropped, subsequent automated client retries effortlessly step through the acquisition gate to spin up an execution path on a healthy container. |
| **Heterogeneous Node Architecture** *(Mixed ARM64 / x86_64 server farm deployment)* | Float data calculations run across disparate hardware stacks. | `struct.pack("<...d")` forces a strict little-endian IEEE 754 double layout. This fully protects our cryptographic audit trails against cross-platform machine-byte drift, guaranteeing absolute log reproducibility. |
