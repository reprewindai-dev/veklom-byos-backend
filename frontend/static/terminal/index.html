How Gladiator Works
Each orchestration request spawns 8 parallel speculative paths. High-dimensional probability transforms evaluate viability. Paths scoring below a dynamic threshold are pruned and discarded. Surviving paths above the lock threshold are committed to execution. Pruned branches are logged here for counterfactual analysis.
