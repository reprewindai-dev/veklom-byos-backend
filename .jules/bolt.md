## 2024-06-25 - Workspace Dashboard Query Batching
**Learning:** In `backend/apps/api/routers/workspace.py`, the dashboard endpoints (`monitoring_metrics` and `workspace_overview`) were making multiple separate `db.scalar()` calls to fetch aggregate statistics from the `ExecLog` table (count, total_tokens, cost, avg_latency) for the same time window. This resulted in the database executing multiple full table scans (or index scans) for the exact same set of rows, creating significant query amplification and potential N+1 style performance problems for heavy workspaces.
**Action:** Replace multiple individual `func.count()`, `func.sum()`, `func.avg()` database calls on the same table with a single batched query that selects all required aggregates at once, drastically reducing DB roundtrips and scan time. Use `metrics_stmt = select(func.count(), func.sum(), func.avg()).select_from(Table).where(...)` to fetch them in one go.
