## 2024-05-18 - Replacing scalars().all() with lightweight Row access
**Learning:** In SQLAlchemy, selecting single tables or multiple columns defaults to returning result `Row` tuples if `.all()` is used. In this codebase, full ORM models (`select(ModelConfig)`) were frequently loaded, tracking state unnecessarily when the endpoints only need `Row` attribute lookups for simple dictionary generation.
**Action:** Replace `select(Model)` with `select(Model.col1, Model.col2)` and `.scalars().all()` with `.all()`. By mapping directly from `Row` using `row.col1`, we avoid N+1 query effects in loops, state tracking overhead, and excessive DB serialization/deserialization.
